title: API Overview
description: Endpoint groups, prefixes, and high-level API surface.
---

Default prefix: `/api/formforge/v1`

Endpoint groups:

- `schema`
- `access`
- `submission`
- `upload`
- `resolve`
- `draft`
- `management`

The management group includes response statistics at `GET /forms/{key}/statistics`. The endpoint returns aggregate statistics for a required form revision and supports date, timezone, and day/week filters. See [Management, Responses, and GDPR](/docs/backend/http-api/management-responses-and-gdpr) for the request filters and response semantics.

You can toggle groups in `formforge.http.endpoints`.

`resolve` now includes targeted field validation endpoints to validate one input without submitting a full payload.

When a form has access-code protection enabled, the `access` group starts and verifies a short-lived challenge before the public schema and form operations return data. The shared code gates access to one form; it does not identify the visitor or provide MFA authentication.
