---
title: useFormForgeAccess
description: Discover form access protection and manage its short-lived challenge flow.
---

Use `useFormForgeAccess` when a custom form loader needs to check whether a shared access code is required before fetching the schema. It discovers the access status, starts a challenge, verifies the code, and keeps the resulting authorization in memory.

```ts [app/pages/contact.vue]
const access = useFormForgeAccess({
  key: 'customer-survey',
  immediate: false
})

const requiresCode = await access.discover()

if (requiresCode && access.state.value === 'challenge') {
  await access.verify('visitor-entered-code')
}
```

The returned state includes `required`, `state`, `challengeId`, `challengeExpiresAt`, `accessToken`, `accessExpiresAt`, `errorCode`, `attemptsRemaining`, and `loading`. Use `startChallenge()` to restart when the server permits it and `invalidateAuthorization()` to discard local authorization.

Pass `access.accessToken.value` to the schema, resolve, upload, and submit calls that need it. Keep the token in memory and never put it in a URL or persistent storage. For the built-in challenge screen, use [FormForgeRenderer](/docs/client/components/formforge-renderer) instead.
