---
title: useFormForgeResponses
description: List, inspect, and delete form responses from an administrative screen.
---

Use `useFormForgeResponses` to manage responses for one form.

```ts [app/pages/contact.vue]
const responses = useFormForgeResponses({
  key: 'contact',
  immediate: false,
  querySync: {
    enabled: true,
    pageKey: 'page',
    perPageKey: 'per_page'
  }
})

await responses.listResponses({ page: 1, per_page: 20 })
```

The composable exposes `list`, `current`, pagination metadata, `loading`, and `error`. Its methods include `listResponses()`, `getResponse()`, `deleteResponse()`, and `refresh()`.

Use `querySync` to keep pagination and selected query values in the current route. Requests use the configured form key, endpoint, scope, and client.
