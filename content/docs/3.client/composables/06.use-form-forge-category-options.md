---
title: useFormForgeCategoryOptions
description: Convert FormForge categories into reactive select options.
---

`useFormForgeCategoryOptions` returns a computed list of `{ label, value, disabled }` options. Provide categories directly or let the composable load them through [`useFormForgeCategory`](/docs/client/composables/use-form-forge-category).

```ts [app/pages/contact.vue]
const categoryOptions = useFormForgeCategoryOptions({
  categories: categories.list,
  includeInactive: false
})
```

When you omit `source` and `categories`, it loads categories using the supplied `query`, `endpoint`, `scope`, or client configuration. The `key` option selects a list from a result object when you pass a larger response shape.

Use the returned value directly as options for a category select. The composable normalizes labels and values and can omit inactive categories with `includeInactive: false`.
