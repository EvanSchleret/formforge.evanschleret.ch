---
title: useFormForgeUploads
description: Upload a file to the staging endpoint for a form submission.
---

Use `useFormForgeUploads` when a form uses staged uploads and your custom interface owns the file input.

```ts [app/pages/contact.vue]
const uploads = useFormForgeUploads({ key: 'contact' })

const result = await uploads.stageUpload({
  field: 'resume',
  file
})
```

The composable returns `uploading`, `error`, and `lastUpload`, along with `stageUpload(input, options?)`. Pass a field name, the selected `File`, and optional revision, endpoint, scope, or access-token overrides.

Use the returned upload token in the submission payload. See [Upload and DateTime Modes](/docs/client/reference/upload-and-datetime-modes) for the available file workflows.
