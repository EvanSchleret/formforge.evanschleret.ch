---
title: useFormForgeDrafts
description: Save, fetch, and delete the current visitor's form draft.
---

Use `useFormForgeDrafts` when a form should save progress before final submission.

```ts [app/pages/contact.vue]
const drafts = useFormForgeDrafts({
  key: 'contact',
  scope: 'team'
})

await drafts.saveDraft(form.state.value, { source: 'signup' })
await drafts.fetchCurrentDraft()
```

The returned state includes `draft`, `loading`, and `error`. Use `saveDraft(payload, meta?)`, `fetchCurrentDraft()`, and `deleteCurrentDraft()` to manage the current draft for the form and scope.

This composable does not submit the response. Call [`useFormForgeSubmit`](/docs/client/composables/use-form-forge-submit) when the visitor is ready to send their answers.
