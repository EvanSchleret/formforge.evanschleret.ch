---
title: useFormForgeForm
description: Load a schema and manage reactive answer state and its validation schema.
---

Use `useFormForgeForm` to build a controlled form around a FormForge schema. By default it loads immediately; set `immediate: false` when your page needs to control the loading step.

```ts [app/pages/contact.vue]
const form = useFormForgeForm({
  key: 'contact',
  immediate: false
})

await form.fetchSchema()
form.setFieldValue('full_name', 'Ada Lovelace')
```

After loading, the composable exposes `schema`, `state`, `zodSchema`, `initialized`, `loading`, and `error`. It builds initial answer values from field defaults and types. Use `setFieldValue()`, `replaceState()`, and `resetState()` to update the local answers.

Pair it with [`useFormForgeSubmit`](/docs/client/composables/use-form-forge-submit) for submission or [`useFormForgeWizard`](/docs/client/composables/use-form-forge-wizard) for page navigation.
