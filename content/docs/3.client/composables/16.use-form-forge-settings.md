---
title: useFormForgeSettings
description: Load, edit, and save form settings in one grouped management PATCH.
---

Use `useFormForgeSettings` to build a settings page without loading or editing the builder schema. Pass a form UUID or key, then call `load()` before changing or saving values.

```ts [app/pages/contact.vue]
const formSettings = useFormForgeSettings({ formKey: 'contact' })

await formSettings.load()
formSettings.settings.value.title = 'Contact us'

if (formSettings.hasChanges.value) {
  await formSettings.save()
}
```

The composable exposes `settings`, `original`, `changedFields`, `hasChanges`, `loading`, `saving`, `error`, and `lastSavedAt`. `save()` sends one PATCH containing only changed settings. It does not send pages, fields, or conditions unless the settings model itself changes them.

Existing submission and access codes are not returned in plain text. The model exposes `has_submission_code` and `has_access_code`; leave their code inputs empty to preserve the current codes. See [FormForgeSettings](/docs/client/components/formforge-settings) for the ready-made UI.
