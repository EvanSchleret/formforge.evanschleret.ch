---
title: useFormForgeBuilder
description: Manage a form-builder draft, schema edits, autosave, and publication.
---

Use `useFormForgeBuilder` when your screen needs to control builder state or actions directly. The [FormForgeBuilder component](/docs/client/components/formforge-builder) already uses this composable for its built-in editor.

```ts [app/pages/contact.vue]
const builder = useFormForgeBuilder({
  formKey: 'contact',
  autosave: true,
  autosaveDelay: 5000
})

const page = builder.addPage()
builder.addField(page.page_key, 'text')
await builder.save()
```

The composable returns the reactive `draft`, `loading`, `saving`, `publishing`, `error`, `publishable`, `lastSavedAt`, and autosave settings. It also exposes actions for editing pages, fields, and conditions, plus `save()`, `publish()`, `unpublish()`, and autosave controls.

Pass `formUuid` or `formKey` to load an existing form. Use `initial` to seed a new draft. See [Standalone Builder](/docs/client/standalone/builder) for a complete screen-level integration.
