---
title: useFormForgeSubmission
description: Use the compatibility alias for the FormForge submission composable.
---

`useFormForgeSubmission` is a compatibility alias for [`useFormForgeSubmit`](/docs/client/composables/use-form-forge-submit). It accepts the same options and returns the same state and methods.

```ts [app/pages/contact.vue]
const submission = useFormForgeSubmission({
  key: 'contact',
  schema: () => form.schema.value,
  state: () => form.state.value
})

await submission.submit()
```

Use `useFormForgeSubmit` in new code unless an existing integration already uses this alias.
