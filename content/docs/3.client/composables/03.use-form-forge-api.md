---
title: useFormForgeApi
description: Get the configured FormForge HTTP client through the API composable alias.
---

`useFormForgeApi` is an alias for [`useFormForgeClient`](/docs/client/composables/use-form-forge-client). It returns the typed client configured by the Nuxt module, or creates a client from the configuration you pass.

```ts [app/pages/contact.vue]
const api = useFormForgeApi()

const schema = await api.getForm('contact')
```

Pass a `FormForgeClientConfig` when a call needs a different base URL, scope, locale, or request hook:

```ts [app/pages/contact.vue]
const api = useFormForgeApi({
  baseURL: 'https://api.example.test',
  defaultScope: 'team'
})
```

Use [`useFormForgeClient`](/docs/client/composables/use-form-forge-client) when you want the composable name to match the returned client directly. For the full configuration and route-scope behavior, see [Nuxt module and scoped routes](/docs/client/overview/nuxt-module-and-scoped-routes).
