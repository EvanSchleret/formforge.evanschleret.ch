---
title: useFormForgeResolver
description: Resolve a form schema from answers and its conditional rules.
---

Use `useFormForgeResolver` when visibility or other schema behavior depends on the visitor's current answers.

```ts [app/pages/contact.vue]
const resolver = useFormForgeResolver({
  key: 'contact',
  payload: () => form.state.value,
  watchPayload: true,
  delay: 250
})
```

The composable returns the latest `schema`, `resolving` state, and `error`. Call `resolve(payload?, options?)` to schedule a debounced request or `resolveNow(payload?, options?)` to send it immediately. Use `clearScheduledResolve()` when your screen needs to cancel a pending request.

Set `watchPayload: true` to resolve whenever the supplied payload changes. The composable stops its watcher and pending timer when its owner component unmounts. Pass the short-lived access token through request options when the form requires an access challenge.
