---
title: useFormForgeStatistics
description: Fetch aggregate response statistics for a specific form revision.
---

Use `useFormForgeStatistics` to request aggregate statistics for one form revision. The query requires `version` and can include date bounds, granularity, timezone, and the test-response filter.

```ts [app/pages/contact.vue]
const statistics = useFormForgeStatistics({
  key: 'customer-survey',
  query: {
    version: '3',
    from: '2026-01-01',
    to: '2026-01-31',
    granularity: 'week',
    timezone: 'Europe/Zurich'
  }
})
```

The composable loads immediately by default. Set `immediate: false` to wait, then call `fetchStatistics(query?)`. The returned state includes `statistics`, `loading`, `error`, and the last query, endpoint, and scope; `refresh()` repeats the last request.

The response contains aggregates, not answer contents. The response rate counts submissions where each question was visible; it is not a form-view or invitation conversion rate. See the [backend statistics API reference](/docs/backend/http-api/management-responses-and-gdpr) for the returned metrics and filters.
