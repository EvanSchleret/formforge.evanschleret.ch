---
title: useFormForgeWizard
description: Navigate the visible pages in a multi-page form schema.
---

Use `useFormForgeWizard` to control page navigation when building a custom renderer.

```ts [app/pages/contact.vue]
const wizard = useFormForgeWizard({
  schema: () => form.schema.value,
  isPageVisible: page => isVisible(page)
})

if (wizard.canGoNext.value) {
  wizard.nextPage()
}
```

The composable returns all schema `pages`, the filtered `visiblePages`, `pageCount`, `pageIndex`, `currentPage`, and `canGoPrevious` / `canGoNext` flags. Use `nextPage()`, `previousPage()`, `goToPage(key)`, `setPageIndex(index)`, and `resetWizard()` to change the current page.

When visibility changes, the current index is clamped to the available page range. Use [`FormForgeRenderer`](/docs/client/components/formforge-renderer) when you want FormForge to provide the complete rendering and navigation interface.
