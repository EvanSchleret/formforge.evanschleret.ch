---
title: useFormForgeSubmit
description: Validate and submit form answers using the configured upload strategy.
---

Use `useFormForgeSubmit` to validate and submit the current answer payload.

```ts [app/pages/contact.vue]
const submitter = useFormForgeSubmit({
  key: 'contact',
  schema: () => form.schema.value,
  state: () => form.state.value,
  validateLocal: true
})

await submitter.submit({
  mode: 'staged',
  meta: { source: 'landing-page' }
})
```

Choose `staged`, `managed`, or `direct` upload mode with the submit options. You can also pass a revision, metadata, test flag, endpoint, scope, and local-validation override. The returned state includes `submitting`, `fieldErrors`, `error`, and `response`.

When the form uses pre-render access protection, provide the current token through the `accessToken` option. This token stays in memory and accompanies the submission request; the existing `submission_code` is a separate form answer requirement.
