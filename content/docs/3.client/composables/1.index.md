Each composable has its own reference page. The sidebar lists the public composables directly, and the global search can find them by name.

| Composable | Purpose |
| --- | --- |
| [useFormForgeAccess](/docs/client/composables/use-form-forge-access) | Discover access-code protection, start a challenge, and verify a code. |
| [useFormForgeApi](/docs/client/composables/use-form-forge-api) | Get the configured FormForge HTTP client through the API alias. |
| [useFormForgeBuilder](/docs/client/composables/use-form-forge-builder) | Manage a form-builder draft, edits, autosave, and publication. |
| [useFormForgeCategory](/docs/client/composables/use-form-forge-category) | List and manage form categories. |
| [useFormForgeCategoryOptions](/docs/client/composables/use-form-forge-category-options) | Convert categories into select options. |
| [useFormForgeClient](/docs/client/composables/use-form-forge-client) | Access the configured FormForge HTTP client. |
| [useFormForgeDrafts](/docs/client/composables/use-form-forge-drafts) | Save, fetch, and delete the current visitor's draft. |
| [useFormForgeForm](/docs/client/composables/use-form-forge-form) | Load a schema and manage reactive form state and validation. |
| [useFormForgeGetForm](/docs/client/composables/use-form-forge-get-form) | Fetch a form schema imperatively. |
| [useFormForgeI18n](/docs/client/composables/use-form-forge-i18n) | Resolve FormForge's built-in translations and locale. |
| [useFormForgeManagement](/docs/client/composables/use-form-forge-management) | Create, edit, publish, and inspect managed forms. |
| [useFormForgeResolver](/docs/client/composables/use-form-forge-resolver) | Resolve a schema from answers and conditional rules. |
| [useFormForgeResponses](/docs/client/composables/use-form-forge-responses) | List, inspect, and delete form responses. |
| [useFormForgeSchema](/docs/client/composables/use-form-forge-schema) | Load a schema and optionally its available revisions. |
| [useFormForgeSettings](/docs/client/composables/use-form-forge-settings) | Load and save form settings with one grouped PATCH. |
| [useFormForgeStatistics](/docs/client/composables/use-form-forge-statistics) | Fetch response aggregates for a form revision. |
| [useFormForgeSubmission](/docs/client/composables/use-form-forge-submission) | Use the compatibility alias for `useFormForgeSubmit`. |
| [useFormForgeSubmit](/docs/client/composables/use-form-forge-submit) | Validate and submit form answers. |
| [useFormForgeUploads](/docs/client/composables/use-form-forge-uploads) | Stage a file for a form submission. |
| [useFormForgeWizard](/docs/client/composables/use-form-forge-wizard) | Navigate visible schema pages. |

Use the [components reference](/docs/client/components) when you want a ready-made FormForge interface. Use a composable when your page needs to control data or workflow directly.
