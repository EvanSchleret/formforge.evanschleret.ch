---
title: useFormForgeManagement
description: Create, edit, publish, and inspect managed forms through the HTTP API.
---

Use `useFormForgeManagement` in an administrative screen that manages form definitions and revisions.

```ts [app/pages/contact.vue]
const management = useFormForgeManagement({ scope: 'team' })
const forms = await management.listForms(false, {
  filters: { category: 'survey', search: 'contact' }
})

await management.patchForm('contact', { title: 'Contact v2' })
```

The composable exposes form list state, loading and error details, field errors, and methods to list forms or routes, create and patch forms, publish or unpublish, delete, load revisions, and compare revisions. `listForms()` and `listFormRoute()` return the rows with a `refresh()` function for the same query.

`createForm()` and `patchForm()` accept either `auto_publish` or `autoPublish`. The client normalizes both names to `auto_publish` in the request payload.

Pass an `idempotencyKey` in mutation options when a write should be safe to retry. See [Management, Responses, and GDPR](/docs/backend/http-api/management-responses-and-gdpr) for the corresponding backend routes.
