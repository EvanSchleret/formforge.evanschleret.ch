---
title: useFormForgeGetForm
description: Fetch a form schema imperatively without an automatic initial request.
---

Use `useFormForgeGetForm` for a one-shot schema request triggered by an action or another piece of application logic.

```ts [app/pages/contact.vue]
const formLoader = useFormForgeGetForm()
const schema = await formLoader.getForm({ key: 'contact' })
```

Pass `version`, `endpoint`, `scope`, or `accessToken` to `getForm()` when the request needs them. The composable exposes the loaded `form`, `loading`, and `error` state, along with `clear()` to discard the local schema and error.

For schema data needed during page rendering, use [`useFormForgeSchema`](/docs/client/composables/use-form-forge-schema) or [`useFormForgeForm`](/docs/client/composables/use-form-forge-form) instead.
