---
title: useFormForgeI18n
description: Resolve the active FormForge locale and translate package labels.
---

Use `useFormForgeI18n` to reuse FormForge's built-in labels in custom interfaces.

```ts [app/pages/contact.vue]
const { locale, t } = useFormForgeI18n({ locale: 'fr' })

const label = t('builder.fieldType.text')
```

The composable returns a reactive `locale` and a typed `t(key, values?)` function. It resolves the locale from the explicit option, Nuxt i18n, or the FormForge runtime configuration, in that order. The package currently includes English and French translations.

The default components already use these translations. Use this composable when a custom wrapper or control needs to stay consistent with them.
