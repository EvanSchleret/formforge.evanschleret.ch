---
title: useFormForgeClient
description: Access the configured, typed FormForge HTTP client.
---

Use `useFormForgeClient` when application code needs direct access to the FormForge HTTP client. With no overrides, it returns the client provided by the Nuxt module. You can pass client configuration to create a client for another API context.

```ts [app/pages/contact.vue]
const client = useFormForgeClient()
const schema = await client.getForm('contact')
```

```ts [app/pages/contact.vue]
const teamClient = useFormForgeClient({
  defaultScope: 'team',
  locale: 'fr'
})
```

The client configuration supports the base URL, scoped routes and parameters, credentials, headers, a fetch implementation, a `beforeRequest` hook, upload mode, datetime mode, and locale. In Nuxt, route parameters can supply values for configured base URLs and scopes. See [Runtime Client](/docs/client/overview/runtime-client) for direct request patterns.
