---
title: useFormForgeSchema
description: Load a form schema and optionally load the available revisions.
---

Use `useFormForgeSchema` when a page needs schema data and may also need to show a revision selector.

```ts [app/pages/contact.vue]
const schemaLoader = useFormForgeSchema({
  key: 'contact',
  immediate: false,
  loadVersions: true
})

await schemaLoader.refresh()
```

The composable exposes `schema`, `versions`, `loading`, and `error`, plus `fetchSchema()`, `fetchVersions()`, and `refresh()`. Set `version` to load a specific revision. By default, `refresh()` loads the schema immediately and loads versions when `loadVersions` is enabled.

Request methods accept endpoint, scope, and access-token overrides. Use [`useFormForgeForm`](/docs/client/composables/use-form-forge-form) when you also need reactive answers and a generated validation schema.
