---
title: useFormForgeCategory
description: List, create, update, and delete form categories through the FormForge client.
---

Use `useFormForgeCategory` for category-management screens. It can load the category list immediately, or wait until you call a method.

```ts [app/pages/contact.vue]
const categories = useFormForgeCategory({
  immediate: false,
  initialQuery: { per_page: 20, is_active: true }
})

await categories.listCategories()
await categories.createCategory({ name: 'Surveys', key: 'surveys' })
```

The composable exposes list, current-resource, pagination, loading, and error state. Its methods include `listCategories()`, `listCategoryRoute()`, `getCategory()`, `createCategory()`, `patchCategory()`, `deleteCategory()`, and `refresh()`.

Pass `endpoint`, `scope`, `client`, or `clientConfig` to use the corresponding API context. The current method options can override the endpoint and scope for an individual request.
