Use a component when you want FormForge's ready-made interface for rendering forms, building schemas, or managing responses.

| Component | Purpose |
| --- | --- |
| [FormForgeBuilder](/docs/client/components/formforge-builder) | Create, edit, save, and publish form schemas. |
| [FormForgeCategoryCreateModal](/docs/client/components/formforge-category-create-modal) | Create a category in a modal flow. |
| [FormForgeRenderer](/docs/client/components/formforge-renderer) | Render and submit a form, with optional access-code challenge. |
| [FormForgeResponse](/docs/client/components/formforge-response) | Display a saved response for moderation or support. |
| [FormForgeSettings](/docs/client/components/formforge-settings) | Edit form settings on a page separate from the builder. |

For task-based walkthroughs, see [How to render a form](/docs/how-do-i/render-a-form), [How to build a form](/docs/how-do-i/build-a-form), and [How to save and publish](/docs/how-do-i/save-and-publish).
